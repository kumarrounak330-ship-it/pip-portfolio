# 🌙 Pip | Junior Dream Engineer - Portfolio

Welcome to the whimsical world of **Pip**, a sleepy Junior Dream Engineer at the Midnight Nursery! Built with glassmorphism, playful interactions, and early-web charm for the hackathon.

👉 **Live Demo:** [https://kumarrounak330-ship-it.github.io/pip-portfolio/](https://kumarrounak330-ship-it.github.io/pip-portfolio/)

---

## ✨ Core Features & Immersion

- ☀️ / 🌙 **Day & Night Mode:** Instant theme toggle for comfortable daytime or nighttime browsing.
- 🔊 **Interactive Sound & Mute Toggle:** Cute giggle audio effects on clicks with complete mute control (`e.stopPropagation()` handling).
- ✨ **Sparkle Cursor Trail:** Dynamic glowing sparkles following cursor movement.
- 🎵 **Floating Music Notes:** Interactive hover effect on **The Lullaby Lab** releasing floating notes.
- 🌟 **Glowing Nightlight Lantern:** Soft glowing pulsing animation and floating stars (`✨`) on hovering over the **Nightlight Collection**.
- 🗺️ **5 Showcase Projects:** Full collection of Pip's work including maps, storybooks, and growth charts.
- ⭐ **Hidden Easter Egg:** A secret interactive star button for curious visitors.
- 📱 **Mobile-Responsive:** Optimized flex layouts and media queries ensuring a smooth experience across phones, tablets, and desktops.
